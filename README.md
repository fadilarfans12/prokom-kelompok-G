# prokom-kelompok-G

Project awal: aplikasi web untuk merekomendasikan tempat makan di daerah Tembalang, Semarang.

Setup cepat (node + npm diperlukan):

1. Install dependency

```bash
npm install
```

2. Jalankan development server

```bash
npm run dev
```

3. Konfigurasi Firebase

Edit file `src/firebase.js` dan masukkan konfigurasi project Firebase Anda (jika menggunakan fitur auth/storage).

Catatan: peta memakai Leaflet + OpenStreetMap. Data contoh ada di `data/restaurants.json`.
